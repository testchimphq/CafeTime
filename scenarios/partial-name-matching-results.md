## Prerequisites



## Test Steps

- Navigate to the Team Search page at url: https://cafetime-demo.web.app/team-search
- Input a partial name into the search field (e.g., 'ali')
- Click the Search button to initiate the search


## Expected Behaviour

The search results should display team members whose names contain 'ali', such as 'Alice', 'Malik', etc.
