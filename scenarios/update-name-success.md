## Prerequisites
- User must have an active account and be logged into the application.
- User must navigate to the settings page where personal information can be updated.

## Test Steps
- Step 1: Navigate to the settings page by clicking on the profile icon in the top right corner and selecting "Settings" from the dropdown menu.
- Step 2: Locate the section labeled "Personal Information".
- Step 3: Find the field labeled "Name".
- Step 4: Enter a new name in the "Name" field, for example, "John Doe".
- Step 5: Click on the "Save Changes" button located at the bottom of the personal information section.
- Step 6: Observe any confirmation messages or loading indicators that appear after submitting changes.
- Step 7: Refresh the settings page to verify the updated name is displayed correctly.

## Expected Behaviour
- Upon clicking "Save Changes", the user should see a confirmation message stating "Your settings have been updated successfully."
- The updated name, "John Doe", should be displayed in the "Name" field after the page refresh.
- No errors should occur during the update process.
