# **App Name**: CafeTime

## Core Features:

- Manager Login: Secure login for managers to schedule and manage shifts.
- Employee Login: Employee login to view schedules and availability.
- Availability Management: Tool to allow employees to request time off or mark unavailability for shifts.
- Conflict Detection: Automatic shift conflict checker that flags potential shift overlaps or understaffing based on employee availability and requests.

## Style Guidelines:

- Primary color: Warm terracotta (#E67E22), evoking a sense of comfort and warmth reminiscent of a cozy café.
- Background color: Light beige (#F5F5DC), providing a soft, neutral backdrop to complement the terracotta.
- Accent color: Mustard yellow (#FFDA63), used sparingly to highlight important actions or information.
- Clean, readable font optimized for schedules and time-related information.
- Simple, clear icons representing shifts, availability, and employee roles.
- Calendar-style layout for visualizing shifts, making it intuitive for users to view their schedules.
